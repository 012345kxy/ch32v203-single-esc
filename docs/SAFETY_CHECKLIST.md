# 安全检查清单

本项目涉及电池、三相功率桥和无刷电机，测试时请优先保证人员与设备安全。

## 上电前

- 检查电池输入正负极、三相桥 MOSFET 方向、栅极电阻和驱动电源。
- 确认 3.3V、5V、主控、FD6288Q 和功率地之间没有短路。
- 初次上电使用限流电源，不直接接入满电动力电池。
- 电机首次测试不装桨、不带危险负载，并固定电机。

## 调试中

- 先验证低压控制和驱动波形，再逐步提高母线电压。
- 持续观察 MOSFET、驱动芯片、电源芯片和采样电阻温升。
- 出现三相短路、异常啸叫、驱动欠压或电流突增时立即断电。
- 不要在电机旋转时触碰转子、焊盘或测试线。

## 发布前

- 在 README 或 Issue 中公开已验证的输入电压、电流、散热和电机条件。
- 未验证的最大电流或功率不要写成承诺值。
- 与安全相关的缺陷应优先修复或明确标注为已知问题。
