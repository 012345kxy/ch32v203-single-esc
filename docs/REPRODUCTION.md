# 复现流程

本文件用于帮助后来者从 GitHub 仓库复现硬件工程。

## 环境

- 立创 EDA 专业版。
- 能够查看或导出原理图、PCB、Gerber、BOM 的本地环境。
- 具备无刷电机、电调、限流电源和示波器调试经验的测试条件。

## 步骤

1. 克隆或下载仓库。
2. 在立创 EDA 专业版中打开 `ProPrj_CH32v203 jlc又打样 优化三项供电路径，烧录点_2026-08-23.epro2`。
3. 检查工程中的原理图、PCB、网络连接、封装和丝印。
4. 根据 README 中的硬件构成核对 CH32V203、FD6288Q、HYG015N04、驱动电源和三相输出路径。
5. 导出 Gerber、钻孔、BOM 和坐标文件，并与打样平台要求核对。
6. 样板回来后先做不上电目检，再用限流电源逐级验证低压供电、主控下载、栅极驱动和三相桥。

## 记录建议

- 记录打样日期、PCB 版本、关键器件批次和异常现象。
- 对电机测试记录输入电压、限流值、PWM 或控制方式、空载电流、MOSFET 温升和异常波形。
- 复现过程中发现的问题建议用 Issue 公开记录，便于后续追踪。
